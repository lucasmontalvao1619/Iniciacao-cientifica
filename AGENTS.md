# AGENTS.md

## Projeto

Desenvolvimento de um aplicativo para planejamento automático de experimentos laboratoriais e análise estatística.

## Objetivo geral

Auxiliar pesquisadores e estudantes no planejamento de experimentos laboratoriais, gerando apoio operacional a partir de protocolos, variáveis experimentais e dados fornecidos pelo usuário.

## Escopo inicial

- Microbiologia.
- Preparo de soluções.
- Diluições seriadas.
- Ensaios em microplacas.
- Organização de controles.
- Repetições experimentais.
- Análise estatística básica e inferencial.

## Escopo futuro

- Química.
- Fenólicos.
- Flavonoides.
- Antioxidantes.
- Ensaios biológicos.
- Novos protocolos experimentais.

## Tecnologias previstas

- Python.
- PyQt6.
- MySQL.
- NumPy.
- Pandas.
- SciPy.
- Matplotlib.

## Arquitetura prevista

- `app/ui/`: interface gráfica futura.
- `app/core/`: regras centrais e modelos conceituais futuros.
- `app/services/`: serviços de aplicação futuros.
- `app/database/`: integração futura com banco.
- `app/assets/`: recursos visuais e arquivos auxiliares.
- `docs/`: fonte principal de contexto.
- `database/`: documentação e arquivos futuros de banco.
- `tests/`: testes futuros.
