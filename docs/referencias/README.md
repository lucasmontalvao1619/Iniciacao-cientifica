# Referências

Bibliografia, referências técnicas e material de apoio do projeto.

## Como registrar

Cada referência deve trazer autor, ano, título, veículo e, quando houver, DOI ou
link. Indicar também a que parte do projeto ela dá suporte — protocolo, fórmula
ou decisão técnica.

Referências que sustentam um protocolo ou fórmula específica devem ser citadas
também no documento correspondente, em [protocolos](../protocolos/README.md) ou
[fórmulas](../formulas/README.md).
