## Resumo do estado

Dos 16 requisitos funcionais, **15 estão implementados** no backend. O único
pendente é a geração de gráficos (RF16), que depende da interface.

Os requisitos de expansão futura (química, fenólicos, flavonoides,
antioxidantes, ensaios biológicos) estão registrados ao final dos
[requisitos funcionais](requisitos-funcionais.md).

Ver [visão geral](../visao-geral.md) para o contexto e
[decisões](../decisoes/README.md) para as justificativas técnicas.
