# Requisitos

## Requisitos funcionais

- Permitir seleção de protocolo experimental.
- Permitir entrada de variáveis do experimento.
- Gerar cálculos operacionais automaticamente.
- Gerar lista de reagentes.
- Gerar lista de materiais.
- Gerar volumes.
- Gerar concentrações.
- Gerar diluições.
- Gerar organização experimental.
- Gerar plano operacional para execução do experimento.
- Calcular média.
- Calcular desvio padrão.
- Calcular variância.
- Executar teste t.
- Executar ANOVA.
- Gerar gráficos.

## Requisitos não funcionais

- Seguir arquitetura modular.
- Permitir expansão futura para novos protocolos.
- Permitir expansão futura para novas áreas experimentais.

## Casos de uso

- Planejar experimento microbiológico.
- Planejar preparo de solução.
- Planejar diluição seriada.
- Planejar ensaio em microplaca.
- Organizar controles experimentais.
- Organizar repetições experimentais.
- Analisar dados experimentais.
