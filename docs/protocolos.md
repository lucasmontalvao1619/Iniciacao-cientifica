# Protocolos

Este arquivo deverá orientar a documentação futura de protocolos laboratoriais.

Cada protocolo deverá registrar:

- nome do protocolo;
- área experimental;
- objetivo;
- variáveis de entrada;
- materiais necessários;
- reagentes necessários;
- volumes;
- concentrações;
- diluições;
- controles;
- repetições;
- etapas operacionais;
- limitações;
- referências.

Nenhum protocolo deve ser implementado antes de estar documentado.
