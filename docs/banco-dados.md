# Banco de dados

Guia para futura modelagem do banco de dados.

## Objetivo

Registrar a modelagem necessária para armazenar protocolos, variáveis experimentais, reagentes, materiais, fórmulas, resultados e histórico de análises.

## Itens a definir futuramente

- entidades principais;
- relacionamentos;
- tipos de dados;
- chaves primárias;
- chaves estrangeiras;
- normalização;
- dados iniciais;
- versionamento do schema;
- regras de integridade.

## Arquivos previstos

- `database/schema.sql`: estrutura futura do banco.
- `database/seed.sql`: dados iniciais futuros.
- `database/diagramas/`: diagramas futuros.

Nenhum schema real deve ser criado antes da definição documental.
