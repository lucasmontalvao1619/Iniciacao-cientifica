# Visão geral

## Título

Desenvolvimento de um aplicativo para planejamento automático de experimentos laboratoriais e análise estatística.

## Objetivo principal

Desenvolver um aplicativo capaz de auxiliar pesquisadores e estudantes no planejamento de experimentos laboratoriais.

## Funcionalidades esperadas

O sistema deverá permitir que o usuário:

- selecione um protocolo experimental;
- informe variáveis do experimento;
- receba automaticamente cálculos operacionais;
- obtenha lista de reagentes;
- obtenha lista de materiais;
- obtenha volumes;
- obtenha concentrações;
- obtenha diluições;
- obtenha organização experimental;
- obtenha um plano operacional para execução do experimento.

## Módulo estatístico

O sistema também deverá possuir um módulo para análise estatística de dados experimentais contendo:

- média;
- desvio padrão;
- variância;
- teste t;
- ANOVA;
- geração de gráficos.

## Escopo inicial

- Microbiologia.
- Preparo de soluções.
- Diluições seriadas.
- Ensaios em microplacas.
- Organização de controles.
- Repetições experimentais.

## Expansões futuras

- Química.
- Fenólicos.
- Flavonoides.
- Antioxidantes.
- Ensaios biológicos.
- Novos protocolos experimentais.

## Diretriz arquitetural

O projeto deve seguir arquitetura modular para permitir expansão futura.
