# Fórmulas

Este arquivo deverá orientar a documentação futura de fórmulas laboratoriais e estatísticas.

Cada fórmula deverá registrar:

- nome;
- finalidade;
- variáveis de entrada;
- unidade de cada variável;
- expressão matemática;
- condições de uso;
- exemplo conceitual;
- referência;
- módulo relacionado.

Fórmulas laboratoriais e estatísticas devem ser documentadas antes da implementação.
