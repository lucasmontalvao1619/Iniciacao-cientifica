# Ícone do aplicativo

Gerado com a ferramenta integrada imagegen em 30/10/2026, para este projeto. PNG original copiado ao workspace; ICNS contém resoluções nativas macOS derivadas sem alterar o desenho. Python/Pillow foi usado apenas para dimensionamento e iconutil para o contêiner ICNS.

Prompt utilizado:

> Create a polished macOS application icon for an academic desktop app named Planejador de Experimentos, for laboratory experiment planning, statistics and charts. No letters or text. Single coherent geometric laboratory flask symbol with three small rising data points integrated into the liquid, not multiple separate cliparts. Deep teal rounded square tile, warm ivory flask, subtle turquoise liquid, restrained dimensional highlights and refined clean edges, excellent silhouette legibility at 32 pixels. Centered symmetrical composition, ample padding. 1024 square icon. No scene, no mockup, no labels. Transparent canvas outside the rounded square.

Arquivos: `app.png` (1254 × 1254 RGBA, saída efetiva da ferramenta) e `app.icns`.
